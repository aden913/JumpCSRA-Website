# Firebase Storage Image Upload Guide

This guide explains how to upload your inflatable images to Firebase Storage and update your application to use them.

## 📋 Prerequisites

1. **Firebase Service Account Key**: Download your service account key from the Firebase Console
   - Go to Project Settings > Service Accounts
   - Click "Generate new private key"
   - Save the file as `firebase-service-account-key.json` in the root directory

2. **Node.js**: Ensure you have Node.js installed

## 🚀 Setup Instructions

### Step 1: Install Dependencies
```bash
# Install the required packages for the upload script
npm install firebase-admin
```

### Step 2: Configure Service Account
1. Download your Firebase service account key (see prerequisites above)
2. Save it as `firebase-service-account-key.json` in the root directory
3. **IMPORTANT**: Add this file to your `.gitignore` to keep it secure

### Step 3: Run the Upload Script
```bash
# Upload all images to Firebase Storage
node upload-images-to-firebase.js
```

## 📁 What Gets Uploaded

The script will upload:
- **Main Images**: `public/assets/inflateables/*.png` → `gs://your-bucket/inflateables/`
- **Detail Images**: `public/assets/inflateables/detail-images/*/` → `gs://your-bucket/inflateables/detail-images/`

## 📊 After Upload

The script generates several files:
1. `upload-results-[timestamp].json` - Detailed results of the upload
2. `url-mappings-[timestamp].json` - Mapping from old local URLs to new Firebase URLs
3. `update-database-[timestamp].js` - Template script for updating your database

## 🔄 Updating Your Application

### Option 1: Update Database URLs (Recommended)
If you store image URLs in your database:
1. Use the generated `url-mappings-[timestamp].json`
2. Update your database records to use the new Firebase Storage URLs
3. Modify the `update-database-[timestamp].js` template for your specific database structure

### Option 2: Update Code References
If image URLs are hardcoded in your application:
1. Find all references to `/assets/inflateables/`
2. Replace them with the new Firebase Storage URLs
3. Use the `firebaseStorage.ts` utility functions for future uploads

## 🛠️ Using the Firebase Storage Utilities

The `firebaseStorage.ts` file provides helpful utilities:

```typescript
import { 
  uploadMainImage, 
  uploadDetailImages, 
  getProductImages 
} from './utils/firebaseStorage';

// Upload a new main image
const mainImageUrl = await uploadMainImage(file, 'Product Name');

// Upload detail images
const detailImageUrls = await uploadDetailImages(files, 'Product Name');

// Get all images for a product
const { mainImage, detailImages } = await getProductImages('Product Name');
```

## 🔍 Verifying the Upload

1. Check the Firebase Storage console to see your uploaded images
2. Test a few URLs in your browser to ensure they're publicly accessible
3. Update a test product to use Firebase Storage URLs and verify it loads correctly

## ⚠️ Important Notes

1. **Backup**: Make sure you have backups of your original images before running the upload
2. **Testing**: Test the upload with a few images first before uploading everything
3. **Permissions**: The script makes all images publicly readable
4. **Cache**: Images are cached for 1 year for better performance
5. **Costs**: Monitor your Firebase Storage usage and costs

## 🔧 Troubleshooting

### Permission Denied Error
- Ensure your service account key has the correct permissions
- Check that Firebase Storage is enabled in your project

### Images Not Loading
- Verify the images were uploaded by checking the Firebase Console
- Check that the URLs are correct and publicly accessible
- Clear your browser cache

### Upload Failures
- Check your internet connection
- Verify file paths are correct
- Ensure the service account key is valid
